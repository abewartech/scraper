## Installation / Usage

> The steps below are generic for a typical Laravel application. Adjust paths, environment configuration, and commands as needed for your specific use case.

1. **Clone the repository**

   ```bash
   git clone https://github.com/abewartech/scraper.git
   cd scraper
   ```

2. **Install PHP dependencies**

   ```bash
   composer install
   ```

3. **Install front-end dependencies (optional)**

   ```bash
   npm install
   # or
   yarn install
   ```

4. **Create environment file**

   ```bash
   cp .env.example .env
   ```

5. **Generate application key**

   ```bash
   php artisan key:generate
   ```

6. **Run database migrations (if applicable)**

   ```bash
   php artisan migrate
   ```

7. **Start the development server**

   ```bash
   php artisan serve
   ```

Visit `http://localhost:8000` in your browser to access the application.
